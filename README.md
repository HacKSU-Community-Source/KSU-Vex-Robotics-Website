# KSU Vex Robotics Website

A mainpage site for the Kent State Vex Robotics club. Developed and designed by the [HacKSU](hacksu.com) community.

## Installation

Clone the repository with 

```bash
git clone github.com/HacKSU-Community-Source/KSU-Vex-Robotics-Website
```

This project uses the React Javascript framework and TailwindCSS for styling. Ensure these are installed via [npm](https://nodejs.org/en/download)

(Run this in the project directory)
```bash
npm install
```

## Purpose/Requirements
Our friends over at the KSU Vex Robotics club have asked HacKSU members to create them a new homepage website to better represent and advertise their work. Below is an overview of the purpose of the site, as well as some project requirements and info that should be on the site.

### Purpose
To inform sponsors of our clubs existence, what club organization is about. We want people to be able to find out more information about our club and provide the opportunity for them to contact us at ksuroboticsteam@gmail.com about involvement or sponsorship.

### Requirements/Additional Info
- Sponsorship packet needs to be easily available on the site (Actual packet will be provided later)
- VEX robotics name and content is fine to use on the site
- Users should easily be able to contact the team at **ksuroboticsteam@gmail.com**
- Users should be able to access the official KSU club page [here](https://www.kent.edu/csi/kent-state-vex-robotics-team)

### Other Requirements
- Team photos
- Past robot photos
- KSU engage page link
- Club leadership history
- Advisors Carl Harrison and Emily Baumgartner mentioned

### Club Description
> We are a competitive robotics team in the program VEX U. We design, manufacture, drive, and program two robots to compete in different games each year.
> We then play this strategic game in matches against other teams at collegiate level competitions. At competitions, we submit an engineering notebook, which is turned into the judges.
> These judges will present awards to a team based on robot performance and their notebook’s rating. We do this for a chance to go to the World Championship and receive awards.

## Contributing
Before contributing please ensure you are in the [HacKSU Discord](https://discord.gg/r8vVvsE) and look at the community source channel, where updates and announcements on the project will be made.

Pull requests are encouraged. A list of actionable development items can be found in the issues tab of this repository. Creating new issues with missed development items is also welcome.

Please ensure branch names are related to the relevant ticket or provide a concise high-level view of what your code does. Also please ensure commit messages describe what changes were made in an accurate and descriptive way. While not enforced, a common method of writing commits is the [Conventional Commit](https://www.conventionalcommits.org/en/v1.0.0/) standard.

### Examples
#### Good Commits
These commit messages allow readers to easily tell what changed about the code base, what got added or changed. Commits in this codebase are not enforced with a certain format but should be readable.
```
feat: Created new main page Hero section.
```

```
fix: Centered contact info box, removing awkward pixel gap previously present.
```

```
Created new signup page with 
```

#### Bad Commits
These commits are non-explanatory, hard to read, or just bad. 
```
Fixed some stuff
```

```
made a new page. react makes this really hard and is my least fav framework blehh
```

```
iourwenfuiydf
```

PR's not following these rules may be denied and asked to correct them, discretion is up to the mantainers of this project (HacKSU leadership).
